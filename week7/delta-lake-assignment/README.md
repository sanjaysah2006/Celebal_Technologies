# Delta Lake Incremental Processing Assignment

## Objective

Perform incremental data processing using Delta Lake and MERGE operation.

## Steps Performed

- Loaded customer master dataset
- Cleaned null values
- Removed duplicates
- Stored data as Delta Table
- Loaded incremental dataset
- Applied MERGE operation
- Updated existing records
- Inserted new records
- Validated row count
- Checked duplicate records

## Technologies Used

- Databricks Community Edition
- Apache Spark
- Delta Lake
- PySpark
