# Celebal Technologies Repository

This repository contains weekly data analysis and SQL assignments for the Celebal Technologies training program.

## Repository Contents

### 📁 week1/
Week 1 datasets and notebooks for the initial training tasks.

### 📁 week2/
Week 2 SQL database design and Superstore analysis assignments.

### 📁 week3/
Week 3 Superstore dataset analysis, SQL scripts, and Jupyter notebooks.

### 📁 week4/
Week 4 advanced analytics and data manipulation tasks.

### 📁 week5/
Week 5 Apache Spark assignments for distributed data processing.

### 📁 week6/
Week 6 additional analytics assignments and advanced techniques.

### 📁 week7/
Week 7 Delta Lake assignments for data lakehouse architecture and incremental data loading.

### 📁 week8/
Week 8 E-commerce Analytics System with data cleaning, analysis, and reporting.

### 📁 Project/
**FMCG Analytics** - Comprehensive Fast-Moving Consumer Goods analytics project with:
- Bronze/Silver/Gold data lakehouse architecture
- Delta Lake implementation
- Power BI dashboards
- Customer, Product, Sales, Inventory, and Promotion analysis

## Learning Outcomes

* SQL database design and query writing
* Data loading and preprocessing
* Exploratory data analysis in Jupyter Notebook
* Aggregations, joins, and performance considerations
* Business insights from sales datasets
* Apache Spark for distributed computing
* Delta Lake for ACID transactions and data versioning
* Data lakehouse architecture (Bronze, Silver, Gold layers)
* ETL pipeline development
* Power BI dashboard creation and visualization
* E-commerce data analytics and reporting
